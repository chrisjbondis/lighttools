Most content on IES files falls into one of two camps: silence, or writing aimed at specifiers already fluent in AGi32. This guide is for neither — it's for the curious buyer or small business owner who's been handed a spec sheet with a strange file attached and actually wants to understand roughly what they're looking at.

What an IES file actually is

An IES file is a standardised text file (ANSI/IES LM-63) describing how a specific fixture distributes light in three-dimensional space — intensity at various angles around the fixture, total lumen output, and physical fixture dimensions. Every genuine photometric fixture file follows this same format, which is what lets lighting design software from different vendors all read the same file correctly.

What it can tell you

  • Luminous flux — the total light output of the fixture, in lumens
  • Distribution pattern — is this a tight spot, a broad wash, an asymmetric throw for wall-washing? The file describes the actual shape of the light output, not just a single beam-angle number
  • A visual read of the beam shape — when loaded into a free photometric viewer, you can actually see a polar plot or 3D render of how the fixture throws light, rather than trying to picture it from a spec sheet number

What it can't tell you

This is the section that separates genuinely useful content from generic "what is an IES file" filler — and it's the honest, important part.

✓ What it covers

  • Light distribution and intensity
  • Total lumen output
  • Physical fixture dimensions

✗ What it says nothing about

  • Electrical listing or certification
  • Surge protection
  • Driver quality
  • Corrosion resistance
  • Warranty
  • Colour consistency between units
  • Suitability for wet, hot or dusty locations
The point worth remembering A fixture can have a beautiful, textbook-perfect IES file and still be a genuinely poor-quality product. The IES file describes optical performance only — it says nothing about build quality, driver reliability, or long-term durability. Don't mistake a good photometric file for a quality guarantee.

Practical use for a non-specifier

Free IES viewer tools exist and are worth knowing about if you're regularly handed spec sheets and want to actually visualise what a fixture does before committing to it — a quick search for "free IES viewer" turns up several reliable options.

The realistic takeaway: understanding roughly what you're looking at in an IES file is genuinely useful. But a proper lighting layout calculation — importing real IES files against actual room geometry to predict lux levels and uniformity — is still a job for someone using the file properly, not a DIY replacement for that process.

How often this actually gets used in practice Dedicated photometric software like DIALux does get used for a quote occasionally, but it's genuinely rare rather than a routine part of most residential or small-commercial jobs. Worth reflecting that honestly here rather than overstating how central full photometric layout work is to a typical project — understanding an IES file is useful, but it's not something most jobs actually require in full.
